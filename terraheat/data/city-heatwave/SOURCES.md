# July 2022 city climate archives

- **Temperature maps:** Copernicus ERA5-Land via the [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The 13–19 July maps take the maximum of 24 hourly 2 m air temperatures per UTC day at each 0.1° target location. A cell with fewer than 24 hourly values is missing for that date. The displayed cells represent the archive's rectangular sampling areas around each city. Some target locations can draw from the same underlying model cell.
- **Station observations:** [Met Office Weather Observations Website](https://wow.metoffice.gov.uk/) and its contributors. [WOW licence information](https://wow.metoffice.gov.uk/support/licence). The layer includes public, download-enabled stations within the archived study boxes with at least 24 usable hours during the event. Screening uses the report timestamp, site ID, public/latest status, stable coordinates and broad physical ranges. Hourly values are means, except gusts use maxima and wind direction uses a circular mean. Rain is mean reported amount. Missing values remain missing.

Each city has a small event index containing station locations and seven map frames. Each station has its own JSON file, with integer UTC hour offsets from the explicit start timestamp. The website requests those files individually on station selection. The data builder reads the AEF research archive without editing it.
